# Name That LLM: extra generations (GPT and Gemini, free Kaggle quota)

Extra single-paragraph passages from the competition's GPT and Gemini models, generated by `abdullah1afify` through the
Kaggle Benchmarks Model Proxy using only Kaggle's free daily AI quota (no paid key, no money). Updated in batches.

## Protocol
- **Prompts:** the public prompt bank of [seyitkaangunes/ntl-extra-api-passages](https://www.kaggle.com/datasets/seyitkaangunes/ntl-extra-api-passages)
  (CC BY 4.0, 1,000 new prompts). Using the same prompts means these passages line up with its 4,998 Claude passages.
- **Request:** one user message, no system prompt: `<prompt> Write a single paragraph of about N words, with no title or headings.`
  Fresh conversation per call; `max_tokens` 16000.
- **Settings:** provider defaults (`setting = default`). A pilot on prompts g0100-g0119 also tried reasoning `none` and `low`;
  those rows are kept and marked in the `setting` column.
- **Length:** N is drawn per (prompt, label) from that label's word counts in the competition training set (numbers only).
- **Cleaning:** whitespace runs collapsed to one space; nothing else.
- **Models (proxy slug → label):** openai/gpt-5.5-2026-04-23 → gpt-5.5; openai/gpt-5.6-luna, -sol, -terra; openai/gpt-6-astra;
  google/gemini-3.1-pro-preview; google/gemini-3.6-flash; google/gemini-3.8-flash. The returned model id is in `model_seen`.

No competition text, id or prompt was sent to any model or is included here.

## Files
- `ntl_generations.csv`: label, prompt_id, setting, target_words, text, model_seen, finish_reason, cost_usd, batch.
- `prompts_used.csv`: the prompts (from the CC BY 4.0 bank above, with attribution).
- `make_tasks.py`: the generation task builder.

## ntl_claude_sessions.csv
Passages from claude-opus-5, claude-sonnet-5, claude-opus-4-8 and claude-opus-4-6, each written by a Claude session pinned to that exact model (one plain paragraph per prompt, same request wording as the main file: "<prompt> Write a single paragraph of about N words, with no title or headings."). Prompts come from the same prompt bank (`prompt_id`). Note: these were generated inside an agent harness (with its own system prompt), not by raw API calls; a classifier trained only on the competition train set recognizes them at about the same rate as real held-out train passages. Grows in batches.
